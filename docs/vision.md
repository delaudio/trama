# Product Vision

## Summary

`trama` is a local desktop workspace for creative AI projects.

Each project combines:

- a visual workflow
- a moodboard of inspirations and references
- a collection of generated outputs

The product is designed for non-technical users working in creative direction, beauty campaigns, still life, product placement, and later interior design.

## Problem

Current tools split the work across too many places:

- references live in folders, chats, boards, or browser tabs
- prompts and workflow logic live somewhere else
- outputs are generated in another tool
- the reasoning behind a concept gets lost over time

This creates friction for creative users who need to return to a project and understand both the process and the inspiration behind it.

## Product Thesis

The workflow should not be isolated from the creative context.

A useful local AI tool for creative direction should let users keep:

- inspiration
- execution steps
- generated outcomes

inside the same project.

## Initial Audience

Primary audience:

- beauty and make-up creative direction
- product campaign concepting

Secondary audience:

- architecture and interior concept exploration

## Positioning

`trama` is a guided creative workspace, not a generic AI node lab.

The product should expose simple creative operations such as:

- remove background
- place product in scene
- generate campaign visual
- upscale
- export result

Instead of exposing raw model names and technical parameters everywhere.

## Design Principles

- local-first project structure
- opinionated templates over blank-canvas complexity
- a small number of high-value nodes
- clear, human-readable labels
- references, workflow, and outputs always connected

## v1 Success Criteria

Version 1 is successful if a non-technical user can:

- create a named project
- upload moodboard references
- open a prebuilt beauty campaign template
- run a small workflow end-to-end
- save and reopen the project later with all context preserved
